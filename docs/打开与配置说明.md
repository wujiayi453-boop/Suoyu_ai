# AI 数据搜索台：打开与配置说明

## 一、直接离线运行（推荐）

此包已经包含岗位、公司、论文、模型、资讯的本地索引，以及新闻正文和论文全文。**不需要 `.env`，也不需要 Elasticsearch。**

1. 安装 Node.js 18 或更高版本：打开 https://nodejs.org，下载并安装 LTS 版本。
2. 解压整个压缩包。请保持 `public`、`src`、`database`、`scripts`、`docs` 五个文件夹与 `启动.bat` 在同一级目录，不要只单独复制某几个文件。
3. 双击 `启动.bat`。
4. 浏览器会自动打开 `http://127.0.0.1:4173`。若没有自动打开，请将这个地址粘贴到浏览器。
5. 使用结束后，关闭弹出的命令窗口即可停止服务。

## 二、如果无法打开页面

1. 确认命令窗口没有提示 “Node.js is not installed”。若有提示，先重新安装 Node.js，再双击启动。
2. 确认浏览器地址是 `http://127.0.0.1:4173`，不是 `file:///.../public/index.html`。
3. 如果端口 4173 被其他程序占用，关闭那个程序后再双击 `启动.bat`。

## 三、可选：连接 Elasticsearch 实时索引

离线版已经可用。只有希望使用另一套实时 Elasticsearch 数据时，才需要配置。

1. 将 `.env.example` 复制并改名为 `.env`。
2. 填写对方电脑能访问的 Elasticsearch 地址、只读 API Key、证书路径和索引名。
3. 双击 `启动.bat` 后，页面右上角显示 “Elasticsearch · 已连接” 即表示成功。

注意：不要把 `.env` 或 API Key 放进公开群、公开仓库或压缩包。`localhost:9200` 只代表当前电脑，不能直接让另一台电脑访问你的 Elasticsearch。

## 四、包内主要内容

- `启动.bat`：双击运行入口。
- `public/`：前端静态资源（`index.html`、`css/`、`js/`），由本地服务直接对外提供。
- `src/`：后端服务代码，启动入口是 `src/server.js`。
- `database/raw/`：新闻全文与论文全文等原始 JSONL 数据，请勿移动或改名。
- `database/generated/`：本地全量搜索索引 `data-full.js` 与两个字节偏移索引。
- `database/mapping/`：Elasticsearch 索引映射。
- `scripts/`：数据构建、导入与冒烟测试脚本。
- `docs/`：项目文档。
- `.env.example`：可选的 Elasticsearch 配置模板。
